## 🚀 Características Principales / Key Features

- **⚡ Motor CUDA Ultra-Bajo VRAM (INT4 / INT3):** Ejecuta modelos de lenguaje, visión y audio localmente en GPUs NVIDIA con poca memoria mediante descarga dinámica por capas (*Auto-Load*) y cuantización GGUF sin depender de APIs externas.
- **🤖 Agentes IA Autónomos + SQL & Tools:** Crea asistentes inteligentes conectados en tiempo real a tus bases de datos SQL, catálogos, APIs y reglas de negocio.
- **📲 Integración Omnicanal Lista para Producción:** Conecta tus agentes directamente a **WhatsApp, Instagram DM y Facebook Messenger**.
- **☁️ Despliegue Híbrido Local + Cloud GPU:** Escala tus modelos en servidores GPU dedicados (RunPod, Vast.ai, DigitalOcean) desde una sola interfaz.
- **🔒 100% Privado / Local-First:** Tus documentos, conversaciones y bases de datos permanecen bajo tu control.
